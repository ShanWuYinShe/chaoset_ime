# 中文互联网分类词库（data/categories/）

本目录收录中文互联网语境中高频输入的热门词组、用语和特有字，按领域和场景细分为 8 大类别。

所有词条均已合并至内置常用词库 `data/dict_common.tsv`（通过 `data/dict_hot.tsv`），开箱即用，无需手动导入。
同时每个类别单独提供 TSV 文件，方便按需查看、扩展或使用 `chaoset-import` 工具导入。

## 格式说明

- 每行 3 列，以制表符 `\t` 分隔：`词 \t 拼音 \t 权重`；
- 拼音以空格分隔，无声调，`ü` 输入为 `v`（如 `雨女无瓜` -> `yu nv wu gua`，`虐菜` -> `nve cai`）；
- 权重（100..4000）按 `ln(权重)/ln(1e6)` 映射到基础词频 1..99，既保证能一次打出，又不会反噬 `的/是/我` 等核心字词。
